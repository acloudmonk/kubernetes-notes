# Interview Preparation

Module-specific questions stay beside their learning material. This directory
holds cross-topic architecture and troubleshooting scenarios.

Use the tags `fundamental`, `implementation`, `internals`, `architecture`,
`security`, `troubleshooting`, `production`, and `senior`.

A strong answer contains a direct response, mechanism, example, tradeoffs,
verification approach, common mistake, and useful follow-ups. When evidence is
missing, state what should be inspected next instead of inventing facts.
