## Recall prompts

1. Draw or narrate the request, reconciliation, or data path.
2. State the guarantee and one condition that breaks it.
3. Name the first three evidence sources for a representative failure.
4. Explain the security boundary and its bypass or limitation.
5. Compare the chosen implementation with one simpler alternative.
6. Predict the outcome of a changed configuration before running it.

Record uncertainty explicitly. A confident but unsupported answer is a revision
target, not a pass.
