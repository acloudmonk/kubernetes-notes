## Videos

- [Flux project overview and demos](https://www.youtube.com/@fluxcd) — Flux project/CNCF. Use current controller demos for reconciliation and status workflows; verify commands against Flux 2.9.6.
- [SigstoreCon sessions](https://www.youtube.com/@sigstore) — Sigstore project. Focus on identity-bound signing, transparency, verification policy, and attestations rather than copying one CI workflow.
- [SLSA supply-chain security talks](https://www.youtube.com/@openssf) — OpenSSF. Use for threat models and provenance levels; the written SLSA specification remains authoritative.
- [Argo CD project channel](https://www.youtube.com/@argoproj) — CNCF Argo. Compare Application-oriented GitOps with the Flux object model; UI and APIs evolve.
