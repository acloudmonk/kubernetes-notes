# Quick Exercises

> **Module:** [08 — Kubernetes Configuration and Secrets](README.md) · Previous: [External stores and rotation](04-external-stores-rotation.md) · Next: [Lab 1 — Observe configuration lifecycle](labs/01-observe-configuration.md)

1. Classify ten application values by sensitivity, source of truth, owner, update mechanism, and failure behavior.
2. Predict update behavior for `env`, normal volume, `subPath`, immutable object, and direct external-store fetch.
3. Draw every principal that can obtain a namespace Secret directly or indirectly through Pod creation/debug access.
4. Design a two-credential database rotation with rollout, observability, revocation, and rollback gates.
5. Compare synced Secret, CSI-mounted file, and application SDK for provider outage and cluster/etcd compromise.
6. Write evidence that proves rotation without displaying either old or new values.
