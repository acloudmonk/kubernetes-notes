# Quick Exercises

> **Module:** [15 — Infrastructure and Production Operations](README.md) · Previous: [Upgrades, recovery, and incident operations](04-upgrades-recovery-incidents.md) · Next: [Lab 1 — Model and test a production topology](labs/01-model-test-topology.md)

1. Draw a Terraform plan/apply flow and mark source, state, lock, credentials, provider, and remote APIs.
2. Choose state boundaries for network, cluster, platform add-ons, and applications; defend the coupling.
3. Write the provider/customer responsibility split for one managed Kubernetes service.
4. Calculate whether a node pool can survive a zone loss plus a rolling update.
5. Explain an HPA/node-autoscaler feedback failure caused by inaccurate requests.
6. Allocate control-plane, shared add-on, idle, egress, storage, and observability costs to owners.
7. Build an upgrade preflight checklist including removed APIs and webhook/add-on compatibility.
8. Define CloudCart RPO/RTO and the evidence that an isolated restore must produce.
9. Write an incident update that separates confirmed impact, hypothesis, mitigation, and next update.
10. Decide whether a regulated hostile workload belongs in a namespace, node pool, or cluster.
