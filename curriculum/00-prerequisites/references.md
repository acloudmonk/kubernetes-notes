# References

- [Linux man-pages](https://www.kernel.org/doc/man-pages/) — processes, signals,
  sockets, and system-call reference.
- [Microsoft WSL documentation](https://learn.microsoft.com/windows/wsl/) —
  supported Windows/Linux environment guidance.
- [PowerShell documentation](https://learn.microsoft.com/powershell/) — command
  and language reference.
- [Python `http.server`](https://docs.python.org/3/library/http.server.html) —
  local lab server; it is not a production server.
- [Git reference](https://git-scm.com/docs) — authoritative Git commands.
- [Pro Git](https://git-scm.com/book/en/v2) — Git mental models and workflows.
- [YAML 1.2.2 specification](https://yaml.org/spec/1.2.2/) — YAML language rules.
- [HTTP Semantics](https://www.rfc-editor.org/rfc/rfc9110) — HTTP behavior.
- [TLS 1.3](https://www.rfc-editor.org/rfc/rfc8446) — TLS protocol specification.
- [Google SRE book](https://sre.google/sre-book/table-of-contents/) — reliability
  and distributed-system operational principles.
