# Quick Exercises

> **Module navigation:** [Docker module home](README.md) · Previous:
> [Compose, operations, and security](04-compose-operations-security.md) · Next:
> [Lab 1 — Secure Python image](labs/01-secure-python-image.md)

Spend 5–15 minutes on each and record evidence.

1. Compare configured `ENTRYPOINT`, `CMD`, and the effective command.
2. Reorder a harmless Dockerfile instruction and observe cache invalidation.
3. Inspect image tag, image ID, and registry digest; explain each identity.
4. Prove two containers on a user-defined network resolve by name.
5. Compare a loopback-published port with an unpublished port.
6. Predict data lifetime for a writable layer, volume, bind mount, and `tmpfs`.
7. Use `docker compose config` to inspect interpolation and the final model.
8. Prove non-root, read-only, resource, and capability controls are effective.
9. Distinguish process exit, failed health, and OOM evidence.

Remove every resource using its explicit lab name.
