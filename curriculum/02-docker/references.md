- [Dockerfile reference](https://docs.docker.com/reference/dockerfile/) — instruction semantics.
- [Build cache optimization](https://docs.docker.com/build/cache/optimize/) — ordering and cache mounts.
- [Multi-stage builds](https://docs.docker.com/build/building/multi-stage/) — builder/runtime separation.
- [Container networking](https://docs.docker.com/engine/network/) — drivers, DNS, and publishing.
- [Docker storage](https://docs.docker.com/engine/storage/) — layers, volumes, bind mounts, and `tmpfs`.
- [Compose specification](https://compose-spec.io/) — portable Compose model.
- [Compose file reference](https://docs.docker.com/reference/compose-file/) — current service fields.
- [Docker security](https://docs.docker.com/engine/security/) — daemon and runtime security.
- [Resource constraints](https://docs.docker.com/engine/containers/resource_constraints/) — CPU and memory.
- [OCI specifications](https://opencontainers.org/) — image, runtime, and distribution standards.

## Videos

- [Docker 101](https://www.youtube.com/watch?v=kwsJIH5TGIg) — Docker, 2018.
  Introduces images, containers, registries, and lifecycle; verify old UI and
  commands against current docs.
- [Docker Tutorial for Beginners](https://www.youtube.com/watch?v=3c-iBn73dDE) —
  TechWorld with Nana, 2020. A long-form walkthrough of images, containers,
  registries, Dockerfiles, and Compose; use the current CLI documentation when
  an older command or interface differs.
- [Docker Compose in 12 Minutes](https://www.youtube.com/watch?v=Qw9zlE3t8Ko) —
  Jake Wright, 2016. A concise mental model for multi-container applications;
  translate the legacy file syntax and commands to the current Compose
  Specification and `docker compose` CLI.
